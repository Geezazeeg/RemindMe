# RemindMe

**Waktumu. Catatanmu. Pengingatmu.**

## 📥 Download

Buka halaman [**Releases**](../../releases) terus pilih installer buat sistem operasi lo:

- **Windows** → `RemindMe_0.1.1_x64-setup.exe` (atau `.msi`)
- **Linux** → `.deb`, `.rpm`, atau `.AppImage`
- **macOS** → `.dmg`

Nggak perlu install Node, Python, atau apa pun. Download, jalankan, selesai.

> Catatan buat Windows: aplikasi ini belum di-*code signing*, jadi SmartScreen kadang muncul peringatan *"Windows protected your PC"*. Itu bukan berarti file-nya bahaya, cuma Windows belum kenal. Klik **More info → Run anyway**. Kalau mau yakin, cek SHA256 checksum yang ada di notes release.

## Fitur sekilas

- **Kalender** bulan, minggu, hari, sama agenda. Event bisa di-drag, di-resize, dibikin berulang.
- **Catatan** rich text, auto-save, bisa di-pin.
- **Catatan nyambung ke event** langsung dari form event.
- **Pengingat** pakai notifikasi sistem, tetep jalan walau window ditutup.
- **Tema** terang, gelap, atau ikut sistem.

Semua data nyimpen di komputer lo sendiri. Nggak ada akun, nggak ada server, nggak perlu internet.

## English

### 📥 Download

Go to [**Releases**](../../releases) and pick the installer for your OS:

- **Windows** → `RemindMe_0.1.1_x64-setup.exe` (or `.msi`)
- **Linux** → `.deb`, `.rpm`, or `.AppImage`
- **macOS** → `.dmg`

No Node, Python, or anything else needed. Download, run, done.

> Windows note: the app isn't code-signed yet, so SmartScreen may show a *"Windows protected your PC"* warning. That doesn't mean the file is dangerous, Windows just doesn't recognize it yet. Click **More info → Run anyway**. If you want extra peace of mind, check the SHA256 checksums in the release notes.

### Quick look

- **Calendar** with month, week, day, and agenda views. Drag, resize, and repeat events.
- **Notes** with rich text, autosave, and pinning.
- **Notes linked to events** right from the event form.
- **Reminders** via system notifications, even when the window is closed.
- **Themes**: light, dark, or follow the system.

All data stays on your own machine. No account, no server, no internet required.
